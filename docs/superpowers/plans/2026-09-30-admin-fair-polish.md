# Admin Fair UI Plan

Goal: Refresh admin shell, teacher/class/audit pages, controls, and dialogs without changing behavior.

1. Shared: clearable inputs, custom select, compact icon actions, bottom-right cancel/save controls, and admin-only playful tokens.
2. Teachers: matching title rail, filter, table row actions, create/edit dialog.
3. Classes: matching title rail, filter, table row actions, class edit dialog.
4. Audit: matching title rail, polished tabs and search panel, compact table actions.
5. Tests: focused TDD per slice, full suite/typecheck/lint, desktop and mobile browser QA.

Review risks: controlled search clearing resets status, custom select preserves FormData and keyboard use, icon actions have names, cancel never submits.
